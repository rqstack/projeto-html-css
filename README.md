# Projeto HTML + CSS — Landing Page Pet

> 📚 **Projeto de estudo.** Feito para praticar os fundamentos de HTML e CSS.

Página inicial simples de um site sobre cuidados com animais de estimação, com menu de navegação, imagem de destaque, título, texto e botão de chamada.

## O que pratiquei

- Estrutura semântica com `header`, `main` e `section`
- Importação de fonte do Google Fonts (Montserrat)
- Estilização de textos, cores, botões e espaçamentos
- `display: inline-block` para posicionar imagem e conteúdo lado a lado
- Responsividade com `@media` para telas de até 600px (layout em coluna no celular)

## Tecnologias

- HTML5
- CSS3

## Como rodar

Basta abrir o arquivo `index.html` no navegador, ou usar a extensão **Live Server** do VS Code.

## Estrutura

```
├── index.html   # estrutura da página
├── style.css    # estilos e responsividade
└── IMG/         # imagens do projeto
```
